# Jetti Finance Server

Jetti Finance Server — серверное приложение на Node.js и TypeScript для работы с документами, справочниками, регистрами, бизнес-процессами и обменом данными Jetti. Оно предоставляет HTTP API и использует Microsoft SQL Server, Redis и очередь Bull.

## Разработчику

- [Документация HTTP API](docs/api.md): авторизация, примеры запросов, основные маршруты и особенности ответов.
- Swagger UI доступен на работающем сервере по адресу `/swagger`. Спецификация в `server/swagger.json` покрывает только часть API; при расхождениях ориентируйтесь на обработчики в `server/routes`.
- Исходный код сервера находится в `server/`, маршруты — в `server/routes/`, модели — в `server/models/`, настройки окружения — в `server/env/environment.ts`.

## Локальный запуск

Для работы нужны Node.js, зависимости проекта, доступные экземпляры SQL Server и Redis и настройки окружения для выбранной среды. Сервер загружает `.env` через `dotenv`; значения подключений и секреты берутся из окружения. Не добавляйте секреты в репозиторий.

```powershell
npm ci
npm run tsc -- --noEmit
npm start
```

`npm start` компилирует TypeScript и запускает сервер. Порт задаётся переменной `PORT`, по умолчанию используется `3000`; `npm run start3001` запускает сервер на порту `3001`. Для успешного старта нужны совместимые схема и данные баз проекта, а также доступ к внешним зависимостям. Скрипты `build` и `build2` выполняют не только сборку, но и push Docker-образа в реестр.
